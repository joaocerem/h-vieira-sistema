# Regras do Projeto

## Objetivo

Este projeto implementa o sistema ERP da H. Vieira Terraplanagem.

Toda implementação deve respeitar a arquitetura conceitual.

## Fonte oficial

A arquitetura conceitual é a fonte oficial das regras de negócio.

Nenhuma regra pode ser inventada durante a implementação.

## Regras

- Nunca duplicar informação financeira.
- Nunca remover auditoria.
- Nunca apagar lançamentos financeiros.
- IA nunca é fonte de verdade.
- Sempre pedir aprovação antes de alterar a arquitetura.
- Sempre documentar mudanças estruturais.
- Sempre manter compatibilidade com a arquitetura conceitual.
